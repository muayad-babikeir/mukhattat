# مُخطِّط

تطبيق ويب تفاعلي لتعليم الطلاب كيفية بناء المخططات الانسيابية (Flowcharts) عبر السحب والإفلات.

## المميزات
- أكثر من 50 سؤالًا موزّعة على 5 مستويات صعوبة
- تتبّع التقدم وحفظه في السحابة
- لوحة متصدرين وتحديات
- واجهة عربية بالكامل مع دعم RTL
